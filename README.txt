Vivek portfolio — static bundle
-------------------------------

Serve this folder (paths are relative; opening the HTML file directly can break some assets):

  cd %USERPROFILE%\Downloads\vivek-portfolio
  python -m http.server 8080

Then open: http://localhost:8080/  (index.html) or http://localhost:8080/vivek-portfolio.html

Add these files from your project if missing (they are referenced by the page):
  images\vivek-hero.png
  resume.pdf

Privacy page nav links to index.html (your portfolio home) and other site pages not included here.
